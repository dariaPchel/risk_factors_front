# 🏥 МЕДСИ: Факторы риска (Лабораторная работа №6)

Полноценное Full-stack приложение для управления медицинскими факторами риска. Реализовано с разделением прав доступа (гость/авторизованный пользователь), загрузкой медиафайлов и управлением состоянием через Redux Toolkit.

---

## 🛠 Стек технологий

### Frontend
- **React 18** + **TypeScript**
- **Redux Toolkit** (слайсы, async thunks, middleware)
- **React Router v6** (маршрутизация)
- **Axios** (HTTP-клиент с интерсепторами для JWT)
- **React Bootstrap** (UI-компоненты)
- **Vite** (сборка и dev-сервер с проксированием `/api`)

### Backend
- **Go (Golang)** + фреймворк **Gin**
- **GORM** (ORM для работы с базой данных)
- **PostgreSQL** (основная база данных)
- **MinIO** (S3-совместимое хранилище для изображений и видео)
- **Swagger / OpenAPI** (документация API)
- **JWT** (аутентификация и авторизация)

---

## ✨ Реализованный функционал

1. **Аутентификация и авторизация:**
   - Вход по email и паролю с получением JWT-токена.
   - Сохранение токена в `localStorage` и автоматическая подстановка в заголовки запросов через Axios Interceptor.
   - Разграничение прав: гости видят только контент, авторизованные пользователи могут создавать, публиковать и удалять **только свои** карточки (`is_creator === 1`).
   - Корректный выход из системы с очисткой состояния Redux и `localStorage`.

2. **Управление факторами риска (CRUD):**
   - **Двухэтапное создание:** сохранение черновика (`draft`) с медиафайлами → заполнение данных → публикация (`published`).
   - Просмотр в виде бесконечной ленты (`FeedPage`) и адаптивной плитки (`GridPage`).
   - Удаление карточек с проверкой прав на стороне бэкенда.
   - Система лайков/дизлайков с сохранением состояния в `localStorage`.

3. **Фильтрация и отказоустойчивость:**
   - Фильтрация карточек по максимальному возрасту (запрос с параметром `?maxAge=N` на бэкенд).
   - **Fallback на mock-данные:** если бэкенд недоступен, приложение автоматически загружает демо-данные, не ломая интерфейс.
   - Индикация загрузки (Spinner) с блокировкой кнопок во время запросов.
